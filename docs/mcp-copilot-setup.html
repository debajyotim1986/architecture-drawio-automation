Connect drawio MCP Server with GitHub Copilot Chat

This page explains how to connect the MCP server in this repository to VS Code Copilot Chat.

For the full end-to-end install (Python, Git, VS Code, extensions), see the canonical installation.md. This page is the short version, focused on the Copilot-Chat connection.

0. Prerequisites

  • Python 3.10+ on PATH (python3 --version on macOS/Linux, python --version on Windows).
  • VS Code 1.99+ (MCP support in Copilot Chat).
  • VS Code extensions installed and signed in:
    • GitHub Copilot (GitHub.copilot)
    • GitHub Copilot Chat (GitHub.copilot-chat) — required for MCP.
  • Optional: Draw.io Integration by hediet (hediet.vscode-drawio) to preview .drawio files.

1. Confirm repository setup

  1. Open the workspace folder in VS Code: AI_Atlassian_copilot.
  2. Verify these files exist in the workspace root:
    • .vscode/mcp.json
    • .vscode/settings.json
    • drawio-mcp-server/

2. Create and activate the Python virtual environment

Run these commands from the drawio-mcp-server/ folder:

cd drawio-mcp-server
python3 -m venv .venv
source .venv/bin/activate

On Windows PowerShell:

cd drawio-mcp-server
python -m venv .venv
.\.venv\Scripts\Activate.ps1

3. Install the MCP server dependencies

pip install --upgrade pip
pip install -e .

This installs:

  • mcp SDK
  • pydantic
  • the local package drawio_mcp_server

4. Verify the server starts

With the venv active, run:

python -m drawio_mcp_server

The server speaks MCP over stdio, so it prints a one-line banner on stderr and then blocks waiting for JSON-RPC input on stdin — that silence is correct. You should see something like:

[drawio-mcp] connected. diagrams=... stories=...

To prove the wire protocol works without VS Code, send a probe and exit:

echo '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}' | python -m drawio_mcp_server

Then press Ctrl+C to stop any manually-launched server.

5. Configure VS Code MCP settings

Open .vscode/mcp.json and make sure the server is configured like this:

{
  "servers": {
    "drawio": {
      "type": "stdio",
      "command": "${workspaceFolder}/drawio-mcp-server/.venv/bin/python",
      "args": ["-m", "drawio_mcp_server"],
      "cwd": "${workspaceFolder}",
      "env": {
        "DRAWIO_DIAGRAMS_DIR": "${workspaceFolder}/diagrams",
        "DRAWIO_STORIES_DIR": "${workspaceFolder}/jira-stories",
        "PYTHONPATH": "${workspaceFolder}/drawio-mcp-server/src"
      }
    }
  }
}
Note: Use the workspace venv Python path so VS Code launches the correct interpreter for the MCP server. On Windows, replace the command value with ${workspaceFolder}/drawio-mcp-server/.venv/Scripts/python.exe.

6. Enable MCP in VS Code settings

Open .vscode/settings.json and confirm these values are present:

{
  "files.associations": {
    "*.drawio": "xml"
  },
  "chat.mcp.enabled": true,
  "github.copilot.chat.codeGeneration.useInstructionFiles": true
}

7. Reload VS Code

  1. Press Ctrl+Shift+P (Windows/Linux) or Cmd+Shift+P (Mac).
  2. Run Developer: Reload Window.

8. Confirm the MCP server is connected

Open GitHub Copilot Chat.

In the chat input area, click the MCP servers indicator. You should see:

  • drawio listed as connected
  • 10 available tools:
    • list_diagrams
    • read_diagram
    • read_diagram_summary
    • create_diagram
    • add_node
    • add_edge
    • update_node
    • remove_element
    • list_stories
    • read_story

9. Use the MCP server from Copilot Chat

Try this prompt in the chat (paths are relative to the workspace root — see prompts/create-diagram.md):

@workspace use the prompt at prompts/create-diagram.md.
The story is jira-stories/PROJ-123.txt.
Save the diagram as diagrams/my-diagram.drawio.

Troubleshooting

If connection fails:
  • Open View → Output and select MCP.
  • Verify the virtual environment is active and python -m drawio_mcp_server works.
  • Confirm the command path in .vscode/mcp.json points to the venv Python (Windows uses .venv/Scripts/python.exe).

Optional: Test with a Jira story

cp examples/sample-jira-story.txt jira-stories/PROJ-123.txt

See examples/sample-jira-story.txt. Then use the prompt above in Copilot Chat to create a diagram file.
