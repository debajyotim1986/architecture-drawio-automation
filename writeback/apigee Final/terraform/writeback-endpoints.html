A · APIs to build and deploy your code – 3 services

1 · Action Hub

Cluster / namespaceExisting Looker GKE · looker-actions
Deployment / identityaction-hub · KSA action-hub-ksa → action-hub@
Exposed asClusterIP https://action-hub.looker-actions.svc.cluster.local
Who may callLooker only (NetworkPolicy from Looker's namespace)
#EndpointCalled by / whenWhat it doesResponses
1POST/Looker, when the hub is registered or refreshedReturns the action list (Looker Action Hub protocol): action writeback, supported on fields tagged writeback_key. Checks the Looker secret in the Authorization header.200 action list · 401 bad secret
2POST/actions/writeback/formLooker, before showing the action (only if a form is used)Returns the input form: field, new value, comment.200 form · 401
3POST/actions/writeback/executeLooker server, once per click (never the browser)Receives the row, user email and id, writeback_allowed and the new value. Checks the Looker secret and writeback_allowed = yes, gets an Entra token (#14), exchanges it at Apigee for an ID&A JWT (#12, cached until expiry), calls the Write-back API (#6) and returns the outcome to Looker.200 success · 401 bad secret · 403 not allowed · 502 downstream failure
4GET/healthzGKE liveness probeProcess is alive.200 · 503
5GET/readyzGKE readiness probeThe Looker secret can be read from Secret Manager.200 · 503

F · Common rules for every endpoint we build

RuleDetail
TransportHTTPS on container port 8443; TLS PEM mounted from Secret Manager at /tls/tls.pem
CorrelationX-Request-Id accepted or generated, passed to every downstream call and logged on every line
LoggingJSON logs with http_status, event, outcome (feed the log-based alerts); never log tokens, secrets or the new value in full
TimeoutsTotal click budget under 5 s; Entra and Apigee 2 s each with one retry; BigQuery 3 s
ErrorsJSON { "error": "<code>", "request_id": "…" }; no stack traces to callers
Probes/healthz liveness, /readyz readiness – cluster-internal only, never exposed through the ILB rules
IdentityWorkload Identity only; no key files, no secrets in environment variables or YAML
ContainerNon-root, read-only root filesystem, all capabilities dropped; 2–6 replicas with PDB and HPA
