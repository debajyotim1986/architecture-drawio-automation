LOOKER WRITE-BACK TO BIGQUERY — JIRA BACKLOG (one item per line number)
Architecture: looker-writeback-oauth2-entra-v5.drawio
  Entra auth token → ID&A JWT via Apigee → Write-back API verifies with JWKS → machine-to-machine on service accounts
  Write permission = Looker group "Writeback Users" → user attribute writeback_allowed = yes (no Microsoft Graph)

How to read each item
  N.  Title                                   → Jira summary
      Team | Depends on                       → assignee team and "is blocked by" links
      What                                    → description
      Done when                               → acceptance criteria
Items are in the order they should be started. Items under one EPIC can be one Jira epic.

    Team: Engineering | Depends on: 52

    Team: Engineering | Depends on: 52

    Done when: Duplicate request returns the same result, one row written.
