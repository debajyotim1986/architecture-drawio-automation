10 AI Projects for Corporate & Institutional Banking on Google Cloud

Modelled on the Letter of Guarantee AI Review pattern: colleague-facing tools that read complex documents, validate them against agreed rules with Gemini, and keep expert judgement, governance and approvals fully in place.

Each project below follows the same proven blueprint — structured extraction, Gemini reasoning over bank-defined rules, a containerised FastAPI service, and full audit traceability — applied to a different high-volume banking process.

1Trade Finance Document Compliance Checker (LC / UCP 600)

Reviews Letters of Credit and presented shipping documents (invoices, bills of lading, insurance certs) against UCP 600 / ISBP rules, flags discrepancies with cited rationale, and drafts refusal or acceptance notices for the checker to approve.

Google services

ServiceRole
Document AI (Custom Extractor)Structured field extraction from scanned trade documents
Vertex AI — Gemini 1.5 ProCross-document consistency and UCP rule reasoning
Cloud RunContainerised FastAPI backend + reviewer UI
Cloud Build + Artifact RegistryCI/CD of container images
FirestoreCase state, discrepancy findings, approvals
Cloud Logging + BigQueryModel traces, audit trail, accuracy dashboards

Flow

Docs upload → Document AI extraction → rule engine + Gemini validation → discrepancy report with citations → human checker approves → decision logged to BigQuery.

Common blueprint across all ten: Document AI / GenAI extraction → Gemini reasoning against bank-defined rules → containerised FastAPI on Cloud Run (built via Cloud Build) → Vertex AI for model serving and evaluation → traces in Cloud Logging and BigQuery for audit. Every project keeps a human approver in the loop and existing governance unchanged.
