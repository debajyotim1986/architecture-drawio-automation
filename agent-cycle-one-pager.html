Agentic Lifecycle

Tableau → Power BI Migration

Shared substrate: PBIP repo in Git (TMDL + PBIR). Every agent reads & writes text-based projects; humans approve every diff via PR.

1

Inventory & Triage

Reads the whole Tableau estate before anything converts — every workbook parsed, scored & wave-planned.
.twb / .twbx XML→asset catalog (SQLite)
calcs · LODs · table calcs→complexity score / tier
blends · custom SQL · user filters→risk flags → agent routing
Server usage stats→wave plan + decommission list
Tableau MCP
2

Bulk Conversion

Runs the accelerator in batches, then turns its binary output into agent-editable source code.
wave of .twb/.twbx→Pulse Convert (batch API) → .pbix
.pbix (binary, per asset)→PBIP: TMDL model + PBIR JSON
PBIP folders→Git repo · branch per wave
catalog vs converted diff→defect work items → Agents 3–7
Why Git/ADO MCP? The agent must do repo & project ops itself — create branches, commit PBIP, open PRs, raise one work item per defect and route it — without hand-written REST glue. It's what turns conversion gaps into a tracked, assignable queue.
ADO / GitHub MCP
3

Data Layer

Custom SQL & joins → Power Query M; Tableau blends → model relationships; refresh strategy per source.
Database MCP (RO)
4

Semantic Model Builder

Turns the converter's raw table dump into a governed model — in bulk, across hundreds of TMDL files.
raw converter TMDL→governed model (names · formats · folders)
Tableau hierarchies + date parts→model hierarchies + date dimension
Tableau parameters→field / what-if / dynamic M params
repeated calc families (YTD·PY·Δ%)→one calculation group
Why: the accelerator translates literally — no standards, no hierarchies, hundreds of duplicated measures. Governance here makes every later fix cheaper and every model BPA-clean before DAX work starts.
PBI Modeling MCP
5

Calc → DAX Remediation

Fixes what the accelerator missed: LODs & table calcs → DAX, every fix proven by an executed query.
PBI Modeling MCPPBI Remote MCP
6

Report Layout & Fidelity

Repairs PBIR JSON: dual-axis, actions → bookmarks/drillthrough, tooltip pages, one org theme.
No MCP — direct file edits
7

RLS Migration

Rebuilds who-sees-what — Tableau security constructs become Power BI roles, then proven per role.
manual user filters→static RLS roles (per region/team)
USERNAME() / ISMEMBEROF() calcs→dynamic RLS · USERPRINCIPALNAME() DAX
entitlement-table joins→one dynamic role + lookup filter
Tableau users & groups→Entra ID UPNs & security groups
Why: security never migrates automatically — accelerators skip it entirely. Every role ships with an impersonated test suite, because a wrong RLS filter is a data breach, not a display bug.
PBI Modeling MCP
8

Validation & Parity Gate

Compares Tableau golden data vs Power BI DAX results + visual diffs → issues the parity certificate. Nothing ships without it.
Tableau MCPPBI Remote MCP
9

CI/CD & Cutover

PR gates → Dev→Test→Prod via Fabric pipelines, auto-docs from TMDL, parallel-run & Tableau decommission.
ADO / GitHub MCP

MCP Servers in the Loop

who calls what
Tableau MCP
Official Tableau server (npx / mcp.tableau.com). Workbook & datasource access, view data for golden datasets.
Called by Agents 1 · 8
PBI Modeling MCP
Microsoft local server. Bulk TMDL/PBIP edits — measures, relationships, roles — with transactions + BPA.
Called by Agents 4 · 5 · 7
PBI Remote MCP
Hosted Fabric endpoint (preview, tenant setting required). Executes DAX & reads model metadata for proof queries.
Called by Agents 5 · 8
ADO / GitHub MCP
What it does: branches, commits, PRs, work items, pipeline runs as agent-callable tools. Why needed: agents write only to branches with human PR review — the MCP is how they operate that Git workflow and route every defect as a tracked work item, with no custom REST glue.
Called by Agents 2 · 9
Database MCP (read-only)
Schema introspection so generated SQL / M is validated against real columns. Optional but cheap insurance.
Called by Agent 3

Operating the Factory

humans · files · numbers

◆Human-in-the-loop checkpoints

GATE 1
Wave plan sign-off — business owners confirm scope, consolidation & decommission list (after Agent 1).
GATE 2
Every PR diff — a human reviews each agent remediation before merge; agents never touch main.
GATE 3
RLS owner approval — data owner signs the security pack per asset (after Agent 7).
GATE 4
UAT + business sign-off — visual diff gallery reviewed before Prod promotion (Agents 8 → 9).

◆The .pbix lifecycle

Stage 2
Born — Pulse Convert returns a .pbix per dashboard.
Stage 2
Dissolved — immediately decompiled to PBIP text (TMDL + PBIR) and committed to Git.
3 – 8
Absent by design — all remediation & validation happens on diffable text, never binary.
Stage 9
Optional return — published straight from PBIP; compile an archive .pbix per release only if a file deliverable is required.

◆Metrics that steer the program

QUALITY
Parity pass rate — % of checks green per asset on first validation run.
SPEED
Cycle time per dashboard — convert → certified; baseline vs agent-assisted.
LEVERAGE
Auto-remediation rate — % of defects closed by agents without human rewrite.
SCOPE
Estate reduction — dashboards decommissioned or consolidated instead of migrated.

Why text, not .pbix: TMDL + PBIR are plain files — agents can edit them, Git can diff them, and every change is a reviewable PR. A binary .pbix allows none of that.
Branching: wave/<n> per conversion batch, fix/<asset>/<defect-id> per agent remediation. Agents never touch main.
Merge gates (CI): TMDL/PBIR schema validation → Best Practice Analyzer → DAX unit tests → parity certificate present. All green or no merge.
Institutional memory: the patterns/ folder is the estate's growing Tableau→DAX/M knowledge base — every solved defect makes the next one cheaper.

vi.

Glossary

the vocabulary of this migration
PBIP
Power BI Project — save format that stores a report + semantic model as plain text folders instead of a binary .pbix. The substrate all agents edit.
TMDL
Tabular Model Definition Language — human-readable text files defining the semantic model: tables, measures, relationships, roles.
PBIR
Power BI enhanced Report format — each page/visual as schema-validated JSON. What Agent 6 repairs.
Semantic model
Power BI's dataset layer: tables, relationships, and DAX measures that reports connect to. Replaces Tableau's embedded data source.
DAX
Data Analysis Expressions — Power BI's calculation language. Target of every Tableau calculated field.
Power Query M
Power BI's data-shaping language. Target for Tableau custom SQL, joins, and data prep.
LOD expression
Tableau Level-of-Detail calc (FIXED/INCLUDE/EXCLUDE) that overrides visual grain. The #1 source of migration defects.
Table calculation
Tableau calc computed over the visible result set (RUNNING_SUM, RANK, WINDOW_AVG). Maps to DAX WINDOW/OFFSET/RANKX.
Data blend
Tableau's post-aggregation join across data sources. Becomes a model relationship or composite model — with documented semantic deltas.
RLS
Row-Level Security — Power BI roles with DAX filters controlling which rows each user sees. Replaces Tableau user filters.
Calculation group
One reusable set of time-intelligence/variance logic applied across measures — collapses hundreds of duplicated Tableau calcs.
Query folding
Power Query pushing transformations back to the source database. Preserving it keeps refreshes fast at scale.
Direct Lake / Import / DirectQuery
Power BI storage modes — the decision that replaces Tableau's extract-vs-live choice.
BPA
Best Practice Analyzer (Tabular Editor) — rule engine that audits models; a CI merge gate in this pipeline.
Golden dataset
Frozen, timestamped snapshot of Tableau-side numbers used as the stable comparison baseline for every remediation iteration.
Parity certificate
Agent 8's signed evidence pack (numeric + visual checks) — the artifact that gates promotion to production.
MCP
Model Context Protocol — open standard exposing external systems (Power BI, Tableau, Git) as tools AI agents can call directly.
Copilot Agent Mode
VS Code mode where Copilot plans and executes multi-step work — editing files, running tasks, calling MCP tools — under human review.
Fabric deployment pipeline
Microsoft Fabric's Dev→Test→Prod promotion mechanism with per-stage parameter rules; Agent 9's delivery rail.
XMLA endpoint
The programmatic connection to published semantic models — fallback path (Tabular Editor) when MCP auth to the service is unavailable.
Wave
A migration batch grouped by shared data source and owner, so each model migrates once and many reports ride on it.
